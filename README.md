### I’m currently working on
**[OSIRIS JSON](https://github.com/osirisjson)**  
OSIRIS (Open Specification for Infrastructure Resource Interchange Schema) defines a vendor-neutral JSON format for describing infrastructure resources, their properties and their topological relationships across heterogeneous IT and OT environments. Generate free, private, point-in-time snapshots of your infrastructure for reports, diagrams, audits, diffs, CMDB/IPAM/DCIM workflows and controlled AI/MCP context.
